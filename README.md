Ответы на вопросы
1. Чем int.TryParse() безопаснее int.Parse() и когда их использовать?
• Безопасность: int.Parse() ломает программу при ошибке ввода, а int.TryParse() просто возвращает false.
• Применение: TryParse — для ввода пользователя (где возможны ошибки); Parse — когда данные гарантированно верны.
2. Когда switch удобнее if/else if? Пример из жизни.
• Когда удобнее: При сравнении одной переменной с конкретными значениями.
• Пример: Выбор напитка в кофе-автомате (1 — эспрессо, 2 — капучино).
3. Что будет в switch, если убрать break после case?
• Произойдет ошибка компиляции, и код не запустится (в C# запрещен неявный переход между заполненными case).
4. Чем отличается = от == и почему это частая ошибка?
• Отличие: = — присваивает значение, == — сравнивает их.
• Ошибка: Новички путают их из-за математики и случайно пишут = внутри if.
5. Можно ли вложить тернарный оператор в другой? Пример из лабы и читаемость.
• Можно ли: Да.
• Пример: string weather = temp >= 20 ? "тепло" : (temp >= 0 ? "прохладно" : "мороз");
• Читаемость: Очень плохая; для сложных условий лучше использовать if/else.
